# WriteOn
Check links. Build strong passwords.

2 client-side cybersecurity tools, no backend, no tracking.

- **Link Checker**: 21 heuristic phishing signals (punycode, @ tricks, lookalike brands, IP hosts) -> SAFE / SUSPICIOUS / RISKY
- **Password Checker**: live strength check, NIST SP 800-63B aligned

**Live:** https://write-on-zai.vercel.app/
**Stack:** Next.js, React, TypeScript
**Team:** Parv, Prince, Zaid, Ajit (PW IOI Noida)

## Run locally
```bash
bun install && bun run dev
```
